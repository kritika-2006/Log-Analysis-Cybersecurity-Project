# Log Analysis and Brute-Force Attack Detection

## Project Description
A lightweight Python script designed to monitor server access logs, parse security events, and detect potential brute-force attacks by identifying excessive failed login attempts from a single IP address.

## Technologies Used
- Python 3.x
- Regular Expressions (`re` module)
